# 나다운하루

운하를 배경으로 나의 하루를 기록하는 개인 캘린더입니다.

- 운영 사이트: https://unharu.vercel.app/
- 구성: 정적 HTML/CSS/JavaScript 화면 + Vercel 서버 함수 + Supabase 인증·저장소
- 이 저장소는 2026-10-16 운영 사이트와 같은 상태입니다. 로컬 전용 푸시 알림과 Google 계정 선택 실험은 포함하지 않습니다.
- 기존 주소와 저장소 식별자 `unharu`는 유지합니다. 이름 변경으로 기존 기록을 옮기거나 초기화하지 않습니다.

## 주요 기능

### 일정과 달력
- 일정 입력·날짜별 상세·반복 일정·캘린더 내보내기
- 캘린더 날짜를 누르면 그 날짜의 입력창과 기록을 바로 볼 수 있습니다. 아래쪽 일정 추가는 접기·펼치기를 해도 작성 중인 문장을 지우지 않습니다.
- 같은 날짜는 할 일 → 회의 → 소비 → 자격증 → 공유 일정 순으로 묶고, 각 분류 안에서는 시간순으로 보여 줍니다. 시간 미정은 분류의 마지막에 둡니다(달력·날짜 상세·목록 공통). 최근 기록은 입력한 순서를 유지합니다.
- 이미 표시된 기록을 누르면 날짜 상세에서 그 기록을 먼저 보여 줍니다.
- 할 일에 시작·종료 시간을 지정하거나 종료 시간 '잘 모름'을 고를 수 있습니다.
- 남은 할 일은 선택한 달의 오늘 이후 미완료 항목만 셉니다. 지난 기록은 지우지 않습니다.

### 여행
- 입력 종류에서 '여행'을 고르고 마지막 날을 정하면, 시작일부터 마지막 날까지 달력에 한 줄로 이어서 보여 줍니다(예: 2박 3일).
- 여행 기간이 겹치면 줄을 나눠서 서로 가리지 않게 표시합니다.

### 오늘 도우미
- 에너지와 가용 시간에 맞춰 오늘의 할 일을 추천하고 시작·완료·완료 취소·미루기를 할 수 있습니다. 외부 AI에 기록을 보내지 않는 로컬 규칙 기반 추천입니다.

### 소비
- 소비 카테고리·필터·월별 소비 비교, 날짜 옆 그날 소비 합계(원 단위)
- 하루 평균 소비: 이번 달은 월초~오늘 소비를 지난 날짜 수로 나눕니다(소비 없는 날 포함, 미래 예약 제외). 지난 달은 그 달 전체 일수 기준, 다음 달은 —로 표시하며 미정·비정상 금액은 빼고 계산합니다.

### 교통
- ODsay 정류장·지하철 검색, 경유지, 귀가 역방향 경로, 자주 가는 경로 저장
- 교통비는 선택한 경로와 환승 조건에 따른 **추정값**일 수 있어 카드의 실제 청구액과 다를 수 있습니다. 실제 결제액으로 고쳐 저장할 수 있습니다.

### 날씨·자격증
- 서울 날씨, 자격증 일정
- 자격증 일정: 시험 검색 → 여러 시험 선택 → 선택한 시험 보기. 처음에는 아무 시험도 선택하지 않으며, 선택은 브라우저·로그인 계정별로 기억합니다(다른 기기로 자동 동기화하지 않음).
- SQLD·TOEIC·JLPT·한국사 심화 일정을 제공합니다. 정보처리기사(공식 일정 재확인 필요)·컴활 1/2급(시험장별 상시)은 공식 안내 링크만 제공하고 임의 날짜를 만들지 않습니다. 2026년 하반기 자료이며 실시간 자동 수집이 아닙니다. 출처와 범위: `docs/exam-settings-v50.md`

### 로그인과 일정 공유
- Google 로그인, 사용자별 비공개 기록 저장
- 개별 일정 공유: 로그인한 나다운하루 사용자가 소유자의 정확한 Google 이메일을 입력하면 공유 일정의 제목·날짜·시간·메모만 읽기 전용으로 볼 수 있습니다.
- 공유 일정은 요일과 함께 이번 주·다음 주(대한민국 날짜 기준 월~일)로 나눠 보여 주며, 범위 밖 일정은 지우지 않고 화면에서만 뺍니다.
- 조회할 이메일을 즐겨찾기에 '누나' 같은 별칭으로 등록할 수 있습니다(최대 20개, 계정·브라우저별 저장, 상대방 권한은 바꾸지 않음).

> 공유 표시는 기본으로 꺼져 있습니다. 이메일을 아는 로그인 사용자는 공유된 일정을 볼 수 있으므로 민감한 내용은 공유하지 마세요. 받은 사람이 이미 읽거나 복사한 정보는 공유 해제만으로 회수할 수 없습니다.

### 화면과 글꼴
- 기본 글꼴은 나눔스퀘어입니다. 메뉴에서 프리텐다드·나눔스퀘어 네오·수트·원티드 산스·본고딕 중 하나로 바꿀 수 있습니다.
- 고른 글꼴은 Google 계정 정보(`user_metadata.unharu_font`)에 저장돼 다른 기기에서도 따라오고, 빠르게 뜨도록 이 브라우저에도 기억해 둡니다.
- 채용 뉴스레터 메뉴·자료는 앱과 공개 파일에서 뺐습니다. 과거 Git 기록은 바꾸지 않았습니다.

## 실행과 검사

- 검사: Node.js 24에서 별도 설치 없이 `npm test` 또는 `node --test tests/*.test.mjs`. 가상 데이터를 써서 실제 ODsay 검색 횟수를 쓰지 않습니다.
- 내 컴퓨터에서 미리보기: `node tools/preview.mjs` → http://127.0.0.1:4259/?test=x (시험 모드라 로그인 없이 화면을 봅니다. 서버 함수와 외부 API는 부르지 않습니다.)
- Google 로그인은 Supabase의 허용 복귀 주소 설정이, 실제 교통 기능은 서버 함수와 ODsay 등록 도메인이 필요합니다.
- 알려진 문제: 일부 비교 검사(5개)는 예전 버전 폴더 경로를 가리켜서 실패합니다. 앱 기능 문제는 아닙니다.

## 설정과 비밀값

- `assets/supabase-config.js`와 교통 서버 함수에는 운영 프로젝트의 **공개용** Supabase 연결 주소·키만 있습니다(관리자 키 아님). 실제 데이터 접근은 로그인과 행별 권한 정책으로 제한합니다.
- ODsay 비밀값은 Vercel 환경변수 `ODSAY_API_KEY`, `ODSAY_ALLOWED_EMAIL`로만 설정합니다. `.env.example`에는 이름만 있습니다.
- 실제 일정·소비·개인 연락처·인증 토큰·환경변수 값·로컬 백업은 이 저장소에 넣지 않습니다.
- 다른 Supabase 프로젝트에서 실행하려면 공개용 연결 설정과 교통 서버 함수의 인증 주소를 함께 검토해야 합니다. 운영 설정을 임의로 바꾸지 마세요.

## 데이터베이스

- `supabase/migrations/`: 나다운하루 전용 구조 변경 파일 3개(원본 그대로). 운영 저장소에는 이미 적용되어 있으니 다시 실행하지 마세요. 새 환경에서는 날짜순으로 검토하고 Google 인증·복귀 주소·저장 권한을 따로 설정해야 합니다.
- 같은 Supabase 프로젝트를 사주 서비스, 멀리건 랩(`mulligan_` 표)과 함께 씁니다. 다른 서비스의 표는 건드리지 않습니다.
- `tests/*-rls.sql`은 접근 권한 검사용 가상 자료입니다. 격리된 시험 환경에서 전체 트랜잭션을 되돌리는 방식으로만 실행하고, 운영에 직접 실행하지 마세요.

## 배포

- 이 GitHub 저장소는 코드 보관용이며, Vercel 자동 배포와 연결하지 않았습니다. 운영 사이트는 Vercel 프로젝트 `unharu`에 직접 올립니다.
- 올릴 때는 저장소 루트를 쓰고, `.vercelignore`로 시험·구조 파일과 예전 공유 스크립트를 뺍니다. 비밀값은 호스팅 설정에만 둡니다.
- 일정 내보내기는 휴대폰 캘린더로 가져오는 방식이며, 서버 푸시 알림과는 다릅니다.
