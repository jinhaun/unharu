# 나다운하루

운하를 배경으로 나의 하루를 기록하는 개인 캘린더입니다.

- 운영 사이트: https://unharu.vercel.app/
- 보관 기준: 2026-10-07 v59 (할 일 시간 범위, 즐겨찾기 별칭, 오늘 도우미, 하루 평균 소비, 나눔스퀘어 적용, 채용 뉴스레터 제외). 로컬 전용 푸시 알림과 Google 계정 선택 실험은 포함하지 않습니다.
- 기존 주소와 저장소 식별자 `unharu`는 유지합니다. 이름 변경으로 기존 기록을 옮기거나 초기화하지 않습니다.
- 정적 HTML/CSS/JavaScript 화면 + Vercel 서버 함수 + Supabase 인증/저장소

## 기능

- 일정 입력·날짜별 상세·반복 일정·캘린더 내보내기
- 캘린더 날짜를 누르면 해당 날짜의 입력창과 기록을 볼 수 있습니다. 아래쪽 일정 추가도 접기·펼치기로 유지하며, 접거나 닫아도 작성 중 문장을 지우지 않습니다. 두 카드가 나란히 배치되는 화면에서는 접힌 입력창과 최근 기록의 높이를 맞춥니다.
- 같은 날짜는 할 일 → 회의 → 소비 → 자격증 → 공유 일정 순으로 묶고, 각 분류 안에서는 시간순으로 표시합니다. 시간 미정은 해당 분류의 마지막에 표시하며, 달력·날짜 상세·목록에 동일하게 적용합니다. 최근 기록의 입력순 정렬은 유지합니다.
- 소비 카테고리·필터·월별 소비 비교
- 서울 날씨, 자격증 일정
- 자격증 일정 → 시험 검색·여러 시험 선택 → 선택한 시험 보기. 처음에는 아무 시험도 선택하지 않습니다. 선택은 브라우저·로그인 계정별로 기억하며 다른 기기로 자동 동기화하지 않습니다. 취소는 기존 선택을 유지합니다.
- SQLD·TOEIC·JLPT·한국사 심화 일정 제공. 정보처리기사(공식 일정 재확인 필요)·컴활 1/2급(시험장별 상시)은 공식 안내 링크를 제공하며 임의 날짜는 생성하지 않습니다. 현재 2026년 하반기 자료로 실시간 자동 수집이 아닙니다. 출처와 범위는 `docs/exam-settings-v50.md` 참고.
- ODsay 정류장/지하철 검색, 경유지, 귀가 역방향 경로, 자주 가는 경로 저장
- Google 로그인 및 사용자별 비공개 기록 저장
- 개별 일정 공유 표시: 로그인한 나다운하루 사용자가 소유자의 정확한 Google 이메일을 입력해 공유 일정의 제목·날짜·시간·메모만 읽기 전용으로 조회
- 공유 일정은 요일과 함께 이번 주·다음 주로 나눠 표시합니다. 대한민국 현재 날짜 기준 월요일~일요일이며, 범위 밖 일정은 삭제하지 않고 조회 화면에서만 제외합니다.
- 조회할 이메일을 즐겨찾기에 등록하고 '누나' 같은 별칭으로 다시 볼 수 있습니다. 최대 20개로 로그인 계정별·브라우저별로 저장되며, 다른 기기로 자동 동기화하거나 상대방의 접근 권한을 변경하지 않습니다.
- 할 일에 시작·종료 시간을 지정하거나 종료 시간 '잘 모름'을 선택할 수 있습니다.
- 오늘 도우미에서 에너지와 가용 시간에 맞춰 오늘의 할 일을 추천하고 시작·완료·완료 취소·미루기를 할 수 있습니다. 외부 AI에 기록을 보내지 않는 로컬 규칙 기반 추천입니다.
- 이미 표시된 이벤트를 누르면 날짜 상세에서 해당 기록을 먼저 보여 줍니다. 날짜 옆에는 해당 날짜 소비 합계를 원 단위로 표시합니다.
- 남은 할 일은 선택한 달의 오늘 이후 미완료 항목만 셉니다. 지난 기록은 삭제하지 않습니다.
- 하루 평균 소비는 현재 달의 월초~오늘 소비를 경과 일수로 나눕니다(소비 없는 날 포함, 미래 예약 제외). 과거 달은 전체 일수 기준, 미래 달은 —이며 미정·비정상 금액은 제외합니다.
- 나눔스퀘어를 제목·본문·메뉴·입력창에 적용합니다. 기존 크기와 배치를 유지하고 글꼴을 기다리는 동안 대체 글꼴로 표시합니다.
- 채용 뉴스레터 메뉴·자료는 앱과 공개 파일에서 제외했습니다. 과거 Git 기록은 변경하지 않습니다.

공유 표시는 기본으로 꺼져 있습니다. 이메일을 아는 로그인 사용자는 공유된 일정을 조회할 수 있으므로 민감한 내용은 공유하지 마세요. 받은 사람이 이미 읽거나 복사한 정보는 공유 해제만으로 회수할 수 없습니다.

## 실행 및 검사

Node.js 24에서 별도 패키지 설치 없이 `npm test` 또는 `node --test tests/*.test.mjs`로 검사합니다. 가상 데이터와 응답을 사용하며 실제 ODsay 검색을 소진하지 않습니다.

정적 화면 미리보기는 저장소 루트에서 `python -m http.server 8080` 실행 후 http://localhost:8080 으로 열 수 있습니다. 이 정적 서버에서는 Vercel 서버 함수가 실행되지 않습니다. Google 로그인은 Supabase의 허용 복귀 주소 설정이 필요하고, 실제 교통 기능은 서버 함수와 ODsay 등록 도메인이 필요합니다.

## 설정과 비밀값

- `assets/supabase-config.js`와 교통 서버 함수에는 운영 프로젝트의 **공개용** Supabase 연결 주소/키가 있습니다. 관리자 키는 아닙니다. 실제 데이터 접근은 로그인과 서버의 행별 권한 정책으로 제한합니다.
- ODsay 비밀값은 Vercel 환경변수 `ODSAY_API_KEY`, `ODSAY_ALLOWED_EMAIL`로만 설정합니다. `.env.example`에는 이름만 있습니다.
- 실제 일정·소비·개인 연락처·인증 토큰·환경변수 값·로컬 백업은 이 저장소에 포함하지 않습니다.
- 다른 Supabase 프로젝트에서 실행하려면 공개용 연결 설정과 교통 서버 함수의 인증 주소를 함께 검토해야 합니다. 현재 운영 설정을 임의로 바꾸지 마세요.

## 데이터베이스 구조

`supabase/migrations/`에는 나다운하루 전용 구조 변경 파일 3개를 원본 그대로 보관했습니다. 사주 테이블과 실제 데이터는 포함하지 않습니다. 운영 저장소에는 이미 적용되어 있으므로 다시 실행하지 마세요. 새 환경에 적용할 때는 날짜순으로 검토하고, Google 인증·복귀 주소·저장 권한을 별도로 설정해야 합니다. 기존 Supabase 프로젝트는 사주와 함께 사용 중이며, 이번 GitHub 저장소 분리는 서버 저장소 분리나 데이터 이동이 아닙니다.

`tests/*-rls.sql`은 데이터 접근 권한 검사용 가상 자료입니다. 반드시 격리된 시험 환경에서 전체 트랜잭션을 되돌리는 방식으로 실행해야 하며, 운영에 직접 실행하지 마세요.

## 파일 안내

- `index.html`, `assets/`: 화면과 기능
- `api/transit-key.js`: 인증된 허용 계정에만 교통 API 연결값 제공
- `data/`: 자격증 자료 (실시간 최신 여부는 별도 확인 필요)
- `docs/`: 교통 요금 추정 및 경로 재사용 안내
- `tests/`: 자동 검사와 과거 원본 비교용 최소 파일
- `supabase/migrations/`: 나다운하루 전용 테이블 및 공유 권한 구조

`assets/sharing.js`, `assets/inline-sharing.js`는 과거 방식의 회귀 검사에만 사용하며 현재 페이지는 불러오지 않습니다. 웹 게시 대상에서도 제외했습니다.

## 게시 범위

이 저장소 업로드는 코드 보관을 위한 것이며 기존 Vercel 프로젝트에 자동 배포 연결을 새로 설정하지 않습니다. 향후 연결 시 저장소 루트를 사용하고, `.vercelignore`로 시험/구조 파일과 이전 공유 스크립트를 제외하세요. 비밀값은 호스팅 설정에 별도로 유지해야 합니다.

교통비는 선택 경로와 환승 조건에 따른 **추정값**일 수 있어 카드의 실제 청구액과 다를 수 있습니다. 일정 내보내기는 휴대폰 캘린더에 가져오는 방식이며 서버 푸시 알림과 동일하지 않습니다.
