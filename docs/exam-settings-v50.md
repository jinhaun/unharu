# 시험 선택 설정 v50

왼쪽 자격증 일정에서 검색하고 여러 시험을 체크한 뒤 ‘선택한 시험 보기’를 누릅니다. 검색어를 바꿔도 체크는 유지되고, 취소·닫기·Escape는 저장하지 않습니다. 모두 해제 후 저장하면 시험 일정만 숨기며 직접 입력한 기록은 삭제하지 않습니다. 이후 시험 설정에서 변경할 수 있습니다.

선택은 localStorage의 별도 `dayflow-exam-settings-v1:` 키에 시험 ID만 저장합니다. 시험 모드/운영, Google 계정/비로그인을 분리하며 개인정보 기록 키는 변경하지 않습니다. 로그인 전 선택은 로그인 계정으로 자동 이전하지 않습니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 다시 설정해야 합니다. 저장 실패는 오류로 안내하며 기존 선택을 바꾸지 않습니다.

## 자료 범위 (2026-10-07 점검)

- SQLD: 기존 2026-10-06 수록 63회 자료 유지. 이번 조회에서 DataQ 원문을 다시 읽지 못했으므로 재검증 완료로 표시하지 않습니다. https://www.dataq.or.kr/www/main.do
- TOEIC: 580~586회 시험·접수 마감·성적 발표를 공식 표와 대조. 접수 시작 등 모든 절차를 포함하는 것은 아닙니다. https://exam.toeic.co.kr/receipt/examSchList.php
- JLPT: 서울실시위원회 제2회 10월 이후 변경 마감·수험표·시험. 성적 발표일은 미확정으로 생성하지 않음. 지역별 실시위원회 안내가 다를 수 있음. https://www.jlpt.or.kr/html/index.html
- 한국사: 국사편찬위원회 80·81회 심화, 10월 이후 일정. 정기 접수·취소좌석 접수·수험표·시험·발표. 기본 시험을 포함하지 않음. https://www.historyexam.go.kr/pageLink.do?link=examSchedule
- 정보처리기사: Q-Net 페이지에서 해당 회차 날짜를 확인하지 못함. 선택 가능하지만 공식 안내 링크만 제공, 캘린더 날짜 없음. https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=1320
- 컴퓨터활용능력 1/2급: 상시 시험이며 시험장별로 다르므로 공통 일자를 만들지 않음. https://license.korcham.net/co/examguide03.do?cd=0448&mm=21

이 목록은 등록된 7개 선택 항목이며 모든 국내 시험의 실시간 검색이 아닙니다. 미등록 시험은 검색 결과 없음으로 안내합니다. 개인 응시 접수·예약과도 연결되지 않습니다. 주관사 변경사항과 다음 연도 일정은 별도 데이터 갱신이 필요합니다.
