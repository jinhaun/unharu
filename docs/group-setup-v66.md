## 동작

- Google 로그인 및 기존 계정 저장 준비 완료 후 사용.
- 왼쪽 ‘그룹 일정’에서 그룹 이름과 구성원에게 보여줄 별칭으로 생성하거나 코드로 참여.
- 그룹 초대 코드는 서버가 무작위로 발급. 원문은 생성/재발급 직후만 제공하며 해시만 저장.
- 코드를 가진 로그인 사용자가 참여할 수 있음. 구성원 100명, 계정당 20그룹 제한.
- 그룹장은 코드 재발급·구성원 내보내기·그룹 삭제 가능. 내보내기 시 초대 코드도 자동 재발급.
- 멤버는 탈퇴 가능. 탈퇴/내보내기/그룹 삭제 시 해당 공유 연결만 제거, 개인 원본 보존.
- 일정 추가 시 ‘내 그룹 불러오기’ 후 그룹 하나를 선택하면 해당 일정만 공유. 선택은 저장 후 초기화.
- 저장된 일정은 날짜 상세의 ‘그룹 공유’ 또는 그룹 메뉴의 일정 선택에서 여러 그룹을 선택/해제.
- 기존 이메일 공유는 별도 설정. 둘 다 선택하면 둘 다 노출되므로 화면에 명시.
- 이번 주+다음 주, 대한민국 시간·월요일 시작, 요일·시작/종료시간·작성자 별칭·메모. 읽기 전용.
- 조회 결과는 메모리에만 유지. 열린 화면에서 1분 간격/화면 복귀 시 재조회하며 숨김/계정 전환 시 제거.
- 이미 읽거나 복사한 내용을 회수하는 기능은 아님.
