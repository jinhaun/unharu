# 경유 교통비 예상 계산

확인일: 2026-10-07. 실제 카드 승인/정산 내역과 연결되지 않은 예상값이다.

## 적용 범위

- 경유 없는 경로: 기존 ODsay 전체 경로 참고 요금을 유지한다.
- 경유 경로: ODsay 도시코드 1000(서울)의 마을(3), 간선(11), 지선(12), 순환(13)버스와 수도권 지하철 코드 2~9만 계산한다. 서울 버스 간 환승도 포함한다.
- 신분당선/GTX/공항철도 등 별도 요금, 수도권 외 구간을 포함할 수 있는 1호선, 다른 지역 버스, 심야버스, 거리 누락, 지하철 재진입, 같은 버스 재탑승, 5회 초과 탑승은 자동 금액을 만들지 않는다.
- 미지원이어도 실제 결제액을 직접 확인하여 저장할 수 있다. 기존 경유 기록은 소급 변경하지 않는다.

## 계산

1. 선택한 노선의 ODsay subPath.distance를 더한다. 도보는 제외한다. 좌표 직선거리로 대체하지 않는다.
2. 성인 교통카드 기본요금: 마을 1,200원, 간선/지선 1,500원, 순환 1,400원, 지하철 1,550원. 이용 수단 중 가장 높은 기본요금 1회 적용.
3. 총 탑승거리 10km 초과분을 5km 단위로 올림하여 100원씩 추가한다.
4. 개별 이용요금 합을 상한으로 둔다. 지하철 단독 상한은 10~50km 5km당 100원, 이후 8km당 100원으로 추정한다.
5. 성인 1인, 동일 교통카드 승하차 태그, 30분 내 환승(21~07시는 60분), 최대 5회 탑승을 가정한다. 조조/카드사 할인과 과거 날짜 요금은 반영하지 않는다.

ODsay 이동거리와 요금 정산거리는 다를 수 있다. 특히 지하철 최단 운임거리나 실제 환승시간을 확인하지 않으므로 확정 결제액으로 표시하지 않는다. 기본요금·규칙은 공식 기준 확인 후 코드 및 테스트를 함께 갱신해야 하며 자동 갱신되지 않는다.

## 저장과 변경

- 기본 금액 구분은 예상 요금. 금액 수정은 실제 결제액으로 전환 후 가능하다.
- 경로나 노선을 바꾸면 재계산하고 확인 체크와 이전 수동 입력을 초기화한다.
- fareEstimate에 계산 방식, 거리, 기본/추가요금, 상한, 가정, 기준 확인일을 보관한다. referenceFare는 원래 예상값으로 유지한다.
- 예상 금액도 기존 소비 합계에 포함되지만 기록 상세에 예상/실제 구분을 표시한다.
