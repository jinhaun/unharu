# 교통 검색 절약·귀가·자주 가는 경로

- v42 보존, v43 기능 추가. 기록/계정/API 설정은 그대로 사용.
- 정류장 검색과 각 경유 구간의 성공 응답은 같은 탭 메모리에서 5분간 재사용(최대 30개). 키는 endpoint와 정렬한 전체 질의 조건. 검색 종류와 이동수단, 방향, 좌표가 다르면 별도 조회. API 키·세션 토큰은 재사용 저장소에 넣지 않음.
- provider 응답을 localStorage/서버에 장기 캐싱하지 않음. 새로고침/로그아웃/계정 이벤트 때 제거. 과거 결과를 실시간 결과로 표시하지 않으며 원 조회시각을 보존. 실패 응답은 재사용하지 않음.
- ODsay 운영정책 https://lab.odsay.com/doc/totalPolicy 의 4.5.10에 무단 저장 제한이 있어 장기 결과 보관은 제공사 허용 확인 전 보류. 메모리 재사용은 현재 화면의 중복 요청 억제 목적. 이 구현이 제공사의 별도 허가를 취득했다는 의미는 아님.
- 요청 중 재클릭/Enter는 추가 요청하지 않음. 입력 변경·계정 변경 후 늦게 도착한 응답은 화면/재사용 저장소에 반영하지 않음. 429 응답은 명확하게 안내하고 1분간 신규 요청을 차단. 자동 재시도 없음. 1분 후 일일 제한이 회복됨을 뜻하지 않음. 실제 잔여 호출수는 ODsay 관리 화면에서 확인해야 함.
- 귀가 설정은 이름·경유지·구간별 수단/지정 노선만 역순으로 설정. 지하철 선택 지점은 유지, 버스는 반대편 정류장을 동일 ID로 단정하지 않고 선택 해제. 기존 요금과 실제 이용 확인을 초기화. 어떤 조회·소비 저장도 자동 실행하지 않음.
- 자주 가는 경로는 이름(40자), 승하차/경유 지점, 검색 종류와 지정 노선 조건을 기존 경로 키에 저장. 기존 자료 유지. API 전체 응답이나 요금 결과 저장하지 않음. 최대 20개이며 초과시 자동 삭제 없음. 같은 조건은 갱신하되 다른 방면 정류장 ID는 구별. 저장 실패 시 메모리 되돌림, 읽기 실패 시 기존 저장값 덮어쓰기 금지. 로컬 브라우저 저장이며 기기 간 동기화 없음.
- 가상 시험 서버: output/unharu-release-tools-2026-10-06-v01/reuse-preview-v43.mjs. 모든 외부 fetch를 가상 응답으로 대체하고 CSP 연결 범위를 self로 제한. 시험 파일은 배포하지 않음.
- 검사: node --test tests/*.test.mjs (61개 통과, 2026-10-07). 실제 ODsay 미호출. 브라우저 가상 응답으로 2구간 첫 조회 2회 → 반복 조회 0회/재사용 2회, 귀가 초안, 즐겨찾기 새로고침 유지 확인. 실제 한도 소진 상태에서의 API 복구는 미검증.
